QUICK START
================================================================================

1. Extract:

   cd AI_Shopping_Agent_Frontend

2. Install:
   pnpm install

3. Configure:

   NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id

4. Run:
   pnpm dev
   # Open http://localhost:3000

5. Build:
   pnpm build
   pnpm start

INTEGRATION REQUIREMENTS
================================================================================

Backend API must provide these endpoints:

Authentication:
  POST   /auth/login              → Get token
  POST   /auth/signup             → Create account
  POST   /auth/google             → Google OAuth
  GET    /auth/me                 → Get user
  POST   /auth/refresh            → Refresh token

Chat:
  GET    /threads                 → List threads
  POST   /threads                 → Create thread
  POST   /search                  → AI search

Shopping:
  POST   /cart/items              → Add to cart
  DELETE /cart/items/{id}         → Remove
  GET    /checkout/{threadId}     → Get state
  POST   /checkout                → Create checkout

Payment:
  POST   /payment/razorpay        → Create order

Orders:
  GET    /orders                  → Buyer orders
  GET    /orders/{id}             → Order detail

Addresses:
  GET    /addresses               → List addresses
  POST   /addresses               → Create
  PUT    /addresses/{id}          → Update
  DELETE /addresses/{id}          → Delete

Seller:
  GET    /seller/products         → List products
  POST   /seller/products         → Create product
  PUT    /seller/products/{id}    → Update
  DELETE /seller/products/{id}    → Delete
  GET    /seller/orders           → List orders

See FRONTEND_README.md for complete endpoint documentation.
